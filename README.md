# Modelo Atômico de Bohr 3D

Simulador interativo do modelo de Bohr: órbitas quantizadas, saltos quânticos, cálculos de raio / energia / velocidade e guia de maquete física.

## Abrir

Abra `index.html` no navegador (não precisa de servidor).

## Deploy

Site estático na raiz. Netlify: publish directory `.`

Uso educacional livre.
